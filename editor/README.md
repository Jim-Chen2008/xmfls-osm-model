# 校园体块 · 3D 模型编辑器

基于 **Three.js** 的 Web 端 3D 模型编辑 / 浏览工具。可以随时导入本地 `.glb`，在视口里选中任意模块做移动、旋转、单轴缩放，实时查看并逐值复制变换数值，编辑完再导出为 `.glb`。附带第一人称漫游，可以走进校园里看看。

默认场景：厦门外国语学校（海沧校区）体块模型（足球场原点），已内联进程序包，**双击 `index.html` 即可运行，不需要本地服务器**。

---

## 快速开始

```
# 直接使用
双击 index.html（Chrome / Edge 106+）

# 修改源码后重新打包
npm install
npm run build      # → dist/app.js + dist/style.css
npm run watch      # 开发时自动增量构建
```

> 打包成单文件是刻意的：浏览器在 `file://` 协议下会拦截 ES Module 的跨文件 `import`，
> 打包后无需起服务即可运行。若你更习惯开发服务器，也可 `npx serve .` 之类，效果一致。

## 功能

### 1. 模型导入 / 导出
- 顶栏「导入 GLB」或直接把 `.glb` / `.gltf` 文件**拖进视口**。
- 顶栏「导出 GLB」导出整个场景；侧栏「导出选中」只导出当前对象（自动烘焙世界变换，位置不跑偏）。
- 导出为二进制 GLB，包含材质与贴图；被隐藏的对象不会写入（`onlyVisible`）。

### 2. 对象编辑
- **点击**视口内任意模块即可选中，**Alt + 点击**选中其父级；也可在场景树里点选。
- 三种手柄：移动（`1`）、旋转（`2`）、缩放（`3`）。缩放支持单轴独立拉伸。
- 坐标系可切「世界 / 局部」；「吸附对齐」打开后移动按 0.5 m、旋转按 15°、缩放按 0.1 步进。
- 选中时显示橙色包围框 + 物体自身轴向的三色坐标轴，手柄落在物体几何中心。
- 面板数值与手柄操作**双向实时同步**。

### 2.1 多选与组合
- **Ctrl / ⌘ + 点击**加选或取消，**Shift + 点击**在场景树里按顺序连选（视口里也支持 Ctrl / Shift 加选）。
- 多选后自动出现**一个整体轴心**：橙色包围框包住全部对象，手柄落在整体中心，直接拖动即可整体移动 / 旋转 / 缩放，成员按世界增量等比联动。
- 面板显示「已选 N 个对象」，位置 = 整体中心，旋转从 0°、缩放从 1.0 起始（即“整块”的额外变换），同样支持输入与 ▲▼ 步进。
- 点「组合」或 `Ctrl+G` 变成一个真正的组节点 `组合_1`（节点就放在整体中心），之后像单个对象一样编辑、导出；`Ctrl+Shift+G` 或「解组」可拆回独立对象。
- 组合 / 解组的层级变化也能撤销、重做。

### 3. 数值显示与复制
- 位置（m，3 位小数）、旋转（°，2 位小数）、缩放（倍率，3 位小数）。
- 每个数值右侧有一对 **▲▼ 步进箭头**：点一下 ±0.1 m / ±1° / ±0.01×，按住 Shift 步长 ×10，按住箭头可连续调整（连续操作会合并为一条撤销记录）。
- 右侧复制图标 → 复制单个数值；每行「复制全部」→ 复制 `x, y, z`。
- 输入框可直接键入数值，回车生效，并记录到撤销栈；方向键 ↑↓ 也能微调。
- 另附「世界位置 / 尺寸 / 三角面 / 材质数 / 层级路径」等只读信息。

### 4. 相机
- 鼠标左键拖拽环绕，右键平移，滚轮缩放。
- `W/A/S/D` 沿视线推拉、左右平移；`Space` 上升、`Shift` 下降（速度随镜头远近自适应）。
- 「指针飞行」按钮或 `B`：锁定指针，鼠标直接改变相机朝向（lookAt），配合 WASD 自由飞行，`Esc` 退出。

### 5. 第一人称漫游
- 「第一人称」按钮或 `V` 进入，落点是当前视角的环绕中心，自动贴地到 1.68 m 视高。
- 重力 + 每帧向下射线取地面高度：上坡、上台阶（≤ 0.65 m）自动抬升，走出屋檐会自然下落。
- `Space` 跳跃、`Shift` 奔跑，轻微步伐起伏；`Esc` 退出回到编辑器视角。

### 6. 其他
- 撤销 / 重做：`Ctrl+Z` / `Ctrl+Shift+Z`（或 `Ctrl+Y`），覆盖手柄拖动、数值输入、步进、组合 / 解组、隐藏操作。
- 网格地面、实时阴影、线框显示、吸附开关。
- 重置视角、聚焦选中（`F`）、保存截图（PNG）、对象隐藏（`Delete`）。
- 底部状态栏：FPS、三角面数、当前对象、相机坐标。

## 实现要点

**轴心归零（`ModelIO.normalizePivots`）**
OSM / GIS 导出的模型常把世界坐标直接烘进顶点，节点自身 `position` 是 `(0,0,0)`，导致变换手柄永远停在场景原点。导入时把每个网格的几何中心搬到原点，并等量补偿节点位移（`L' = L·T(C)`）：外观完全不变，但每个对象都有了可用的轴心，面板里的坐标也变成真实位置。共享几何体会先克隆，避免互相影响。

**撤销栈**
`History` 保存 `{ label, undo, redo }` 命令，变换类命令记录前后两份 `position/quaternion/scale` 快照。手柄拖动在 `dragging-changed` 时开/关事务，数值输入在 `focusin` 开、`change/focusout` 关，因此一次拖动 / 一次输入只产生一条记录；连点步进箭头在 1.2 s 内按 `mergeKey` 合并，撤一次就回到最初。

**多选的整体变换**
多选时并非把对象塞进临时父节点，而是用一个位于整体中心的代理对象（`__multi_pivot`）承载手柄：拖动前记录轴心与每个成员的世界矩阵，拖动中把 `Δ = pivotWorld · pivotStart⁻¹` 左乘到成员世界矩阵，再经父节点逆矩阵转回局部变换后分解写入。因此不同父级、不同缩放的成员也能严格同步；撤销则直接回放成员快照。

**组合**
`Ctrl+G` 会新建 `Group`（位置设在整体中心），再对每个成员调用 `Object3D.attach()`，保持世界位置不变。解组反向操作。两者都写成可逆命令，所以能进撤销栈。

**视角适配**
不直接用「包围球 / sin(fov)」（对扁平校园会拉太远），而是把包围盒 8 个角点投影到 NDC 迭代求解距离，画面填充率约 86%。

**第一人称贴地**
每帧向下打一条射线取落点高度，配合重力把视点压回 `地面 + 眼高`；水平移动前先试探目标点地面高度，超过台阶阈值（0.65 m）就判定为墙体并拦截，因此不会穿楼。

## 已知限制

- 只读取 GLB / 自包含 GLTF；使用 **Draco / Meshopt 压缩**的模型需先解压（会给出明确提示）。
- 不支持骨骼动画播放与编辑（动画数据在导入时保留但不播放）。
- 隐藏对象不会写入导出的 GLB —— 这是 `onlyVisible` 的预期行为。
- 撤销栈在重新导入模型时清空（旧对象已释放）。
- 需要支持 WebGL2 的浏览器（Chrome / Edge 106+、Firefox 120+、Safari 16+）。

## 换默认模型

```bash
# 1. 放入新模型
cp 你的模型.glb models/campus.glb

# 2. 重新生成内联 base64 并打包
node -e "const fs=require('fs');fs.writeFileSync('src/assets/default-model.b64',fs.readFileSync('models/campus.glb').toString('base64'))"
npm run build
```
