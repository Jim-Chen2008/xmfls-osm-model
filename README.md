# 厦门外国语学校（海沧校区）· OSM 三维模型 + 校门编辑器

以 OpenStreetMap 数据算出的校园体块为底，按实拍照片把**南大门 / 喷泉广场 / 花圃**做 1:1 尺度复原（单位：米），
配套一个浏览器里就能跑的 **GLB 查看器** 和一个 **Three.js 模型编辑器**。

![](https://img.shields.io/badge/three.js-r128%20%7C%200.160-000) ![](https://img.shields.io/badge/model-glTF%2FGLB-orange)

## 目录结构

| 路径 | 说明 |
|---|---|
| `viewer/` | 查看器（单文件，双击 `index.html` 即可看，模型已 base64 内联） |
| `editor/` | Three.js 模型编辑器（导入 GLB / 选中 / 移动旋转缩放 / 导出 GLB）→ `editor/README.md` |
| `models/` | 交付用的 GLB（含本次修好的校门版本） |
| `src/` | 早期逐次迭代的校验页（bbox / 拖拽 / 机位标定等），可当调试参考 |
| `lib/` | 查看器用的 three.js r128 |
| `_build/` | 建模脚本（Python / Blender）：OSM 解析、大门重建、材质贴图、场景拼装 |
| `_ref/` | 参考照片（实拍正立面、大门近景、航拍、喷泉花圃） |
| `dist/` | 打包好的独立 HTML 成果（OSM 模型总览 / 坐标校准叠图 / 足球场原点说明） |
| `_shots/` | 过程渲染图（**未入库**，仅本地留存） |

## 怎么跑

### 1) 查看器（最简单）

直接双击 `viewer/index.html`（Chrome / Edge 106+）。模型内联为 base64，**不需要本地服务器**。

- 左键旋转、右键平移、滚轮缩放
- 数字键 `1`–`5`：街道立面 / 校门内侧 / 喷泉花圃 / 广场全景 / 鸟瞰
- 右侧「参考照片」切换实拍对照图；底部可开关阴影、自动旋转、标注、参考图

### 2) 编辑器

`node_modules/` **不入库**（80 MB），克隆后按下面三行还原：

```bash
cd editor
npm install        # 还原依赖：three@0.160.1 + esbuild@0.21.5
npm run build      # 打包 src/ → dist/app.js + dist/style.css
```

> `npm run watch` 是开发时监听重编译。
> 打包原因：`file://` 协议下浏览器会拦截 ES Module 的跨文件 `import`（CORS），
> 打成一个 IIFE 单文件后 `index.html` 双击即可用，不用起本地服务器。
> 若只想看效果，仓库里的 `editor/dist/` 已经打包好，直接双击 `editor/index.html` 也行。

### 3) 建模脚本（可选）

`_build/` 下是 Python 脚本，多数要在 **Blender 5.x** 里跑（headless 也行），例如：

```bash
blender -b -P _build/gate_only.py     # 重建 GATE_* 校门组
blender -b -P _build/build_scene.py   # 拼装查看器场景
```

其余 `parse_osm_model.py` / `make_textures.py` / `align_and_gate.py` 等在系统 Python 下也能跑。

## 模型规格（节选）

- **大门**：中央门洞 13.5 × 5.6 m；两侧依次 门卫房墩（5.2 宽，带门 / 雨棚 / 三级台阶 / 小窗）、高墩 6.3 × 6.0 m、汽车侧门 2.8 m（折叠门）、端墩 4.1 × 3.6 m；上方横墙 5.6–9.4 m 跨中门洞与两侧门卫房，街道面金色校名；白幕墙板 1.2 m 见方。
- **广场**：椭圆铺装 中心 (270.5, 7.5)、半轴 22.5 × 29.5 m，45° 菱形分格，1.45 m 石材方砖 + 每 5.8 m 深色分格带。
- **喷泉**：池外径 17.4 m，坐凳式池壁高 0.46 m，中央两级鼓座，水面 0.30 m。
- **花圃**：以喷泉为圆心的弧形花池，内径 9.9 m、宽 2.8–8.4 m，50+ 球形灌木。
- 坐标沿用校园 GLB 世界坐标：大门中心 (281.13, 24.49)，喷泉中心 (244.32, −8.92)。

## 本次改动：校门“多出来的一坨”

原模型里 **门卫房 `GATE_gh` 被拉到 9.40 m**，与横墙顶齐平；它进深 4.25 m 远大于横墙的 1.2 m，
于是从横墙背后鼓出一大块，白色压顶还和横墙上沿连成一片大平顶 —— 从斜视角看就是“多出来的一坨”。

修正内容（`models/gate_campus_current-edited-20261027-2338-fixed.glb`）：

| 项 | 改前 | 改后 |
|---|---|---|
| `GATE_gh_±1` 墙身 | z −0.35 → 9.40 | z −0.35 → **5.60**（顶面与横墙底面平齐） |
| `GATE_gh_cap_±1` 压顶 | z 9.40 → 9.54 | z **5.60 → 5.74**，后缘收到横墙正面，不外凸 |
| 侧面瓷砖 UV | 9.75 m 高 | 按 0.6103 压缩，**保持 1.2 m 方板不变形** |
| 横墙 / 校名 / 门洞 / 门 / 雨棚 / 台阶 / 窗 | — | **未改动**（附属件最高仅 3.55 m） |

两侧同步处理以保持镜像；网格总数 370 不变，材质与贴图无损。

## 已知简化

- 校名用华文行楷近似原碑行书，非逐字复刻。
- 植被为体块化表现（球冠 + 噪声），非逐叶建模。
- 校园其余建筑沿用 OSM 体块，未做立面细化。
